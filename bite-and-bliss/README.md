# Bite & Bliss — Restaurant / Food Ordering Application

A responsive restaurant website and front-end food ordering demo built with React JS.

## Technologies
- React JS and JSX
- JavaScript
- CSS
- React Router
- React hooks: useState and useEffect

## Features
- Home, About, Menu and Contact pages
- Responsive navigation
- Menu search and category filtering
- Add-to-cart and quantity controls
- Cart total calculation
- Contact form validation and feedback

## Installation
1. Install Node.js.
2. Open this folder in Visual Studio Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed in the terminal (usually http://localhost:5173).

## Build
Run `npm run build` to create the production build in the `dist` folder.

## Note
This is a front-end academic project. The order and contact forms demonstrate client-side interactions; they do not send orders to a real restaurant server.
